# Конфиденциальность

zapret не собирает и не отправляет данные о вас и вашем компьютере. В приложении нет аналитики, счётчиков и рекламы. Весь трафик идёт напрямую на сайты, которые вы открываете: это не VPN и не прокси.

## Куда приложение обращается само

| Адрес | Зачем | Когда |
| --- | --- | --- |
| `api.github.com`, `github.com` | Проверить и скачать новую версию приложения и запрета | Раз в сутки и по кнопке. Отключается в «Настройках» |
| `raw.githubusercontent.com` | Обновить список адресов и файл hosts из репозитория Flowseal | Только по кнопке |
| `hyperion-cs.github.io` | Скачать набор адресов для глубокой проверки | Только при глубокой проверке |
| Сайты из ваших целей: YouTube, Discord, игры из каталога и ваши сайты | Проверить, открываются ли они с выбранным способом | При подборе и раз в 5 минут, пока обход включён |
| `8.8.8.8`, `1.1.1.1`, `77.88.8.8` | Проверить, есть ли интернет, прежде чем менять способ | Вместе с проверкой целей |

Эти обращения не содержат ничего о вас, кроме того, что видит любой сайт при открытии: ваш IP-адрес.

## Что меняется на компьютере

Удаление приложения убирает:

- службу `zapret` и драйвер WinDivert;
- папку `C:\ProgramData\zapret` с настройками и журналом;
- исключение Защитника Windows для этой папки, если вы согласились его добавить.

Записи в файле hosts и безопасный DNS появляются, только если вы включили их сами. Удаление их не трогает: DNS выключается в разделе «Проверка», а записи приложения в hosts помечены строками `# zapret-app start` и `# zapret-app end`, рядом лежит копия файла `hosts.zapret-backup`.

## Ссылки, которые открываются в браузере

Кнопки «Поддержать», «Предложить игру» и ссылки на GitHub открывают сайты в вашем браузере. Дальше действуют правила этих сайтов.

# Code signing policy

Установщик приложения собирается автоматически на GitHub Actions из исходного кода этого репозитория ([.github/workflows/release.yml](.github/workflows/release.yml)). Подписываются только файлы, собранные из этого кода. Сторонние файлы запрета входят в установщик без изменений, как их выпускает Flowseal.

Сейчас установщик не подписан. Подпись через SignPath Foundation будет подключена после одобрения заявки, и тогда здесь появится строка о ней.

## Роли

| Роль | Кто |
| --- | --- |
| Авторы (committers) | [dOne](https://github.com/Arkadiy2009) |
| Ревьюеры | [dOne](https://github.com/Arkadiy2009) |
| Подтверждают подпись релиза | [dOne](https://github.com/Arkadiy2009) |

Все участники входят в GitHub с двухфакторной защитой. Изменения от сторонних авторов принимаются только через пулреквесты после проверки.

## Конфиденциальность

Приложение не передаёт данные о пользователе. Какие адреса оно открывает и зачем, описано в [PRIVACY.md](PRIVACY.md).
